Before you use Auto-Backup

Auto-Backup makes mirror backups with Windows' robocopy: every source folder you add is copied into every destination folder you add.

Mirror means mirror. It does not only add and update, it also deletes anything in the destination's copy that is no longer in the source. Pointed at the wrong folder, it will reshape that folder to match the source.

Unsafe setups are refused (overlapping paths, duplicate folder names, a folder onto itself) and every run asks first. Double-check your destinations regardless.

Dirs to Copy

Why is this higher than Total Source Dirs?

Because the backup also creates each source folder itself at the destination: C:\Photos into D:\Backup produces D:\Backup\Photos. One extra root per source, per destination.

Why not just raise Total Source Dirs to match?

Because they answer different questions. Total Source Dirs is what exists inside your sources; Dirs to Copy is the work the next run would do.

It only appears when the two disagree. On incremental runs, where the roots already exist, it stays hidden.

Copy Speed

What it does

An estimating aid, nothing more. It seeds Estimated Time in the Summary panel, and gives a running backup's progress bar and ETA a starting speed before real throughput can be measured.

What it does not do

It does not limit or throttle an actual backup. Backups run at whatever your drives deliver; this changes only the predictions on this screen.

It tunes itself

After each backup copying at least 100 MB, that run's measured speed is blended in (70% old, 30% new). Smaller runs are too brief to measure and are ignored.

Typing your own value makes it the new baseline.

Resize & Canvas

Resize

Scales each image to fit the width and height you set, keeping its aspect ratio. Exact output dimensions depend on each image's proportions.

Only W scales to that width, height following. Only H does the reverse. Both fits within that box. Leave both blank to apply a canvas without resizing.

Canvas

Places each image on a fixed-size surface filled with the background color. Smaller images are padded, larger ones cropped.

Use it when every output must share identical dimensions, such as 1920×1080 carousel slides.

Keep the canvas at least as large as your biggest source image, or your resize target if set. Smaller crops the image.
